# Investigação e Uso de Medidas de Centralidade de Redes Complexas para Suporte à Tomada de Decisão em Diferentes Contextos
Uma rede complexa é constituída por elementos interconectados e podem representar múltiplos sistemas complexos da realidade, como cidades e aeroportos. Há uma diversidade de opções para analisar redes complexas, que nos permitem encontrar fatores influentes no sistema como um todo. Dentre essas opções, a análise de medidas de centralidade (grau, intermediação, proximidade, eigenvector, entre outros) é notável, proporcionando a identificação de elementos influentes e centrais na rede. Nesse cenário, o projeto apresentado visa relacionar o aspecto teórico de redes complexas com o aspecto prático, investigando e aplicando as medidas de centralidade em contextos práticos, auxiliando a tomada de decisão.
